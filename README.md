# stable-challenge-image-test

For challenge details see: https://github.com/galilai-group/stable-challenge-image-test/blob/main/CHALLENGE.md

The website is published from `docs/`. Scores are generated by the administrator's evaluator. Model files remain private; participant emails appear only when anonymity is disabled.

## Development

```bash
uv sync
uv run pytest                                        # ~6 s, no downloads
```

- `test_submission.py MODEL.onnx` is the participant-facing check (see [CHALLENGE.md](CHALLENGE.md#validate-submission)).
- `data/sample` holds three preprocessed training images (one per domain) in the `data/train` format, used by
  `test_submission.py` and the tests.
- `example_submission/model.onnx` is a reference model that passes `test_submission.py`.
- The tests in `tests/` cover `training_data.py`, `evaluate.py` and `test_submission.py` (including many malformed
  submissions) using synthetic data.
